# PrismFlow logo

| File | Use |
|---|---|
| `prismflow-logo.png` (1600×900) | Main logo on its dark background: README, website, splash |
| `prismflow-logo-800.png` (800×450) | Same, smaller, for the web |
| `prismflow-logo-square.png` (1024×1024) | Avatars and social profiles |
| `prismflow-logo-transparent.png` | White logo on a transparent background, for dark surfaces only |
| `prismflow-app-icon.png` (1024×1024) | Source of the app icons in `src-tauri/icons` (`npx tauri icon branding/prismflow-app-icon.png -o src-tauri/icons`) |

The menu-bar icon (`src-tauri/icons/tray.png`) is the logo's one-colour silhouette; macOS tints it to match the menu bar.

Background colour: `#0F0F0F`. The logo is white, so on light backgrounds use the versions with their own dark background.
